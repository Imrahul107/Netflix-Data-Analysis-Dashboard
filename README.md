# Netflix Data Analysis Dashboard

## 📊 Project Overview

This is an end-to-end Netflix Data Analysis project focused on cleaning, analyzing, and visualizing customer and subscription data.

The project uses Python, Pandas, SQL, Excel, and Power BI to transform raw data into meaningful business insights and an interactive dashboard.

## 🎯 Project Objectives

- Clean and prepare raw Netflix customer data
- Handle missing and inconsistent values
- Perform data analysis using Python and SQL
- Analyze customer behavior and subscription patterns
- Calculate important business metrics
- Build an interactive Power BI dashboard
- Present insights through clear and interactive visualizations
